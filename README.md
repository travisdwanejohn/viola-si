# Viola S.I

Viola S.I — a personal AI assistant web app with an alien-themed interface.

## Run it

Open `index.html` in any modern browser, or enable GitHub Pages on this repo (Settings > Pages > Deploy from branch: `main`) to get a live link.

## Features

- Chat with tools (ask, summarize, write, explain, analyze, code, brainstorm, plan, study, translate)
- Voice input and spoken replies
- Prompt library and playground
- Customizable alien theme
- Installable as a home-screen web app (mobile)

## Notes

This is the static shared version. Conversations and settings stay in the visitor's own browser — nothing is sent to a server.
